# Kairo — Telegram Mini App

Адаптивный веб-трекер для iPhone 11 и других устройств. Работает на Windows для разработки и открывается на iPhone через Safari после публикации по HTTPS.

## Возможности
- Счётчик калорий с быстрым добавлением и настраиваемой дневной целью.
- Записи веса и продолжительности сна по датам.
- Ежедневные чек-листы привычек и заметки.
- Переключение дат, история и сводка прогресса.
- Сохранение в браузере вне Telegram и синхронизация данных аккаунта через Telegram WebApp CloudStorage внутри Mini App.
- Экспорт/импорт резервной копии JSON.
- PWA manifest и service worker для установки и базовой работы офлайн.

## Запуск для проверки
Из-за ограничений PWA service worker требует HTTPS или localhost. Самый простой вариант на Windows — открыть терминал в этой папке и выполнить:

```bash
python -m http.server 8080
```

Затем открыть `http://localhost:8080` на компьютере. Для установки на iPhone разместите содержимое папки на HTTPS-хостинге (например, GitHub Pages).

## Установка на iPhone 11
1. Опубликуйте файлы на HTTPS-хостинге.
2. Откройте опубликованный адрес именно в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Запустите приложение с появившейся иконки.

## Хранение и синхронизация данных
Внутри Telegram Mini App приложение использует Telegram WebApp CloudStorage: данные привязаны к Telegram-пользователю и могут загружаться на другом устройстве при запуске Mini App под тем же аккаунтом. При первом запуске локальные и облачные данные объединяются: непустые локальные значения не заменяются пустыми облачными, а игровое состояние выбирается по времени последнего изменения. Облачный снимок записывается отдельными версиями, а метаданные публикуются только после записи и проверки всех частей.

При открытии обычной веб-страницы вне Telegram используется только localStorage этого браузера; автоматической синхронизации там нет. Для резервной копии используй «Настройки → Экспорт JSON».


## Разработка и тесты

Требуется Node.js 18 или новее. Запусти проверки перед публикацией:

```bash
npm test
node --check app.js
node --check state-utils.js
node --check service-worker.js
```

Чистые функции нормализации и объединения состояния находятся в `state-utils.js`. Регрессионные тесты лежат в `tests/state-utils.test.cjs`. GitHub Actions запускает синтаксические проверки и тесты при push и создании pull request.
